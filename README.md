## Cómo explorar los trabajos

Cada carpeta incluye el objetivo, el método y los resultados. Los cuadernos de Python contienen código, tablas y gráficos ejecutados: se pueden leer directamente en GitHub. El libro de Excel se puede descargar para explorar sus fórmulas y filtros.

Para ejecutar los cuadernos localmente con Python 3.12:

```sh
python -m pip install -r requirements.txt
python ejecutar.py
```

Los dos datasets públicos necesarios están incluidos junto con sus fuentes y licencias.
