## Sobre este portafolio

Estos trabajos fueron realizados durante mi formación universitaria. Los casos y datasets no representan empleos ni servicios prestados a las empresas mencionadas.

Los cuadernos conservan el código académico original. Para esta presentación se retiraron salidas guardadas y conclusiones numéricas que no se volvieron a verificar. Los datos originales de Python no están incluidos; cada carpeta explica qué archivo se necesita. No se presentan métricas de rendimiento como resultados validados.

El caso de Excel conserva la entrega académica grupal y sus consignas docentes; mi contribución está descrita en su carpeta. No se atribuye la autoría de las plantillas o los datos.
